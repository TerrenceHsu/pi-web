# Release Notes — v0.0.26 Export Markdown

## 范围

把 SQLite 持久化的 session messages 渲染为 Markdown 文件并提供浏览器下载。

## Added

### Backend

- `src/pi_agent_core_py/web/markdown_export.py`——纯函数 renderer
  - `ExportMessage` dataclass
  - `render_session_markdown(title, messages, *, max_chars, max_bytes)`
  - `_sanitize_filename`——path traversal / 控制字符 / 80 字符 / RFC 5987 UTF-8
  - `MAX_EXPORT_CHARS = 2_000_000` / `MAX_EXPORT_BYTES = 5_000_000`
- `GET /api/sessions/{sid}/export/markdown`——SQLite messages → Markdown 下载

### Frontend

- `api/client.ts`：`requestBlob` + `downloadBlob`
  - try/finally 释放 Blob URL
  - `setTimeout(0)` 延迟 revoke 防 Safari 中断下载
- `api/sessions.ts`：`exportMarkdown(sid)`
- `SessionSidebar.vue`：Export 按钮

## Security

### 三道边界

1. **Blob URL 释放**：`downloadBlob` 用 try/finally 包裹；`setTimeout(0)` 防 Safari 中断
2. **Content-Disposition CRLF 阻断**：`_sanitize_filename` 正则阻断 `\x00-\x1f`（含 CR/LF）；`test_21_crlf_injection_blocked` 显式证明
3. **MCP env value 不导出**：按 role 过滤（只导出 user / assistant）；不读 `mcp_servers` 表；不扫描用户正文中的 secret 字符串；system prompt / request_id / toolResult / MCP env 一律不导出
