## 范围

## Added

### A1 — API smoke 3 项

- 并发 prompt 返回 409
- 重名 SKILL 上传返回 409
- 不存在的 MCP command 返回 502

### A2 — Playwright MCP tool lifecycle 真链路

`tests/e2e/mcp-tool-lifecycle.spec.ts`——用真实 stdio MCP server（`tests/fixtures/fake_mcp_stdio_server.py`）覆盖完整生命周期：

add → test connection → enable tool → disable tool → enable tool → disable server → delete

### A3 — 真实 GLM e2e_probe

`tests/integration/test_real_glm_tool_use.py`——真实 GLM 多轮 tool_use smoke。

防幻觉 token `PROBE_OK_ALPHA_7F3A`：模型必须在回答中包含此 token 才视为"通过"，避免 LLM 编造结果导致测试假阳性。
