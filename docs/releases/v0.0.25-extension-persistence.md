# Release Notes — v0.0.25 Extension Persistence

> **Tag**: `v0.0.25-extension-persistence`
> **Commit**: `b4640aa`
> **Date**: 2026-07-13
> **阶段**: P1-C（Extension Persistence）

## 范围

让用户上传的 Skills + MCP server 配置 + MCP disabled tools **跨重启恢复**。

## Added

### C1 — ExtensionSQLiteStore

- 3 表 + `schema_meta` version 单例（`id=1 CHECK`）
- 共享 session_store connection（`:memory:` 模式必须共享）
- 逐行隔离 decode（`list_rows` + `decode_uploaded_skill` / `decode_mcp_server`）
- CHECK 约束（`enabled` / `desired_enabled` / `source_kind` / `transport`）

### C2 — Skill Persistence

- Upload 加 DB 写入 + mutation lock + rollback
- Enable / disable 加持久化 + 非 uploaded Skill 不写 DB
- `DELETE /api/skills/{name}`（DB row 为准 + 403 非 upload）
- Startup restore（逐行 sha256 + `model_validate` + metadata 强制覆盖 `source_kind=upload`）

### C3 — MCP Persistence

- Add / enable / disable server + tool 加 DB 写入 + lock + rollback
- `desired_enabled` vs `attached` 语义（`enabled` = `desired_enabled` 兼容）
- env 只持久化 `env_keys`（**绝不**存 value）
- 结构化 tool key（`server_name`, `raw_tool_name`）不 split("__")
- Delete server cascade disabled tools

### C4 — Startup Restore + Failure Isolation

- `_resolve_mcp_env` 从 `os.environ` 读 value
- `_safe_extension_error` 空 secret 保护 + 长度降序替换
- `_restore_mcp_servers`（逐行 decode + 10s timeout + 失败隔离）
- Missing env → `restore_status=needs_env` + `missing_env_keys`
- Shutdown detach MCP transport
- `restore_status` 枚举：`not_requested` / `attached` / `needs_env` / `error`

### C5 — Browser Validation + Release

- 5 persistence E2E + 安全扫描（`P1C_SECRET_MARKER_7F3A91`）
- tag `v0.0.25-extension-persistence`

## Security

- **MCP env values 严格不回显**：response 类型只有 `env_keys`；前端表单用 `type=password + autocomplete=new-password`；提交后 `resetForm()` 清空所有字段
- **env value 永不持久化**：SQLite 主文件 / WAL / SHM / API response / `body.innerText` / logs 均无 env value
- 安全扫描 token `P1C_SECRET_MARKER_7F3A91`——存入 env value 测试，扫描所有泄露面
