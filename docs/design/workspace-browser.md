# Workspace 多标签与本机浏览器

范围：纯本机 Web；分隔线下的 Markdown/网页多标签和双栏分屏，然后接入真实 Chromium。
不是 iframe，不接管日常 Chrome/Edge，不注册 Agent 浏览器工具。

## 交付顺序

1. 标签容器：打开多个文件/网页、关闭/切换、左右或上下双栏，Session 隔离。
   浏览器式标签栏末尾“＋”创建网页；只在分隔线下保留一个 New Markdown。
   当前标签突出显示，另一个分屏标签弱提示；左右/Home/End 切换、中键/×关闭，关闭当前标签选相邻项。
   Markdown 草稿仅存前端内存，切换不丢失；关闭脏标签、刷新/离开有提醒。
   关闭标签不是删除文件，保存保留 SHA 冲突校验。账号退出清空所有内存草稿。
2. 本机浏览器：按需启动受 Chromium sandbox 保护的独立浏览器；每个 Session
   一个非持久 BrowserContext，网页为多个 Page。前端接收媒体或截图，发送有界导航/鼠标/键盘操作。
   支持地址栏、前进/后退/刷新、点击、滚动、键盘、中文输入和登录弹窗页。
3. 闭环：前后端单元测试、隔离真实 Chromium 验收、静态检查、生产构建与本机加载。

## HD 图片模式与响应优化（2026-09-09—10）

以下规则适用于手动选择或故障回退的 **HD screenshots**；当前优先可见浏览器默认使用下节媒体模式。

- 已用内部 CDP Screencast → 认证 WebSocket 二进制帧替换前端 450ms 截图轮询。
  操作帧 JPEG 88、推送上限 15 fps；内容停止变化后补无损 PNG，重复 JPEG 不覆盖高清静态帧。
  无用户交互超过 1 秒后只发送无损帧：页面变化时最高约 2 fps，无变化不重复传图；
  这也避免光标/动画持续覆盖高清画面，不以无操作视频播放作为本轮目标。
- 默认勾选 HD，最高 2 倍物理像素；单页物理像素不超过 400 万，单帧不超过 8 MiB。
  取消 HD 使用 1 倍像素降低资源消耗。像素坐标与 CSS 点击坐标分开，视口版本拒绝缩放前旧帧点击。
- 改变视口后先完成一次当前 surface 截图，再启动动态帧，避免旧 compositor 内容带上新视口元数据。
  后端检查 PNG/JPEG 图像头、前端检查解码尺寸，拒绝与采集视口不符的像素；传输使用帧自身的坐标快照。
  图片 CSS 比例固定，不用 `max-height` 单独压缩高度；分屏变化时不会把旧帧拉伸成新尺寸。
- 页面显示实际接收像素、近 2 秒帧率和导航到响应 commit 的耗时；不是完整网页加载时间。
  状态栏高度固定，避免数字变化触发视口反复缩放。
- 每页共享一个帧源、每订阅只保留最新帧；WebSocket 收到显示确认后才发下一帧。
  账号最多 6 个观看连接；关闭/隐藏网页标签或切离 files/隐藏主页面时停止该观看连接。
- 导航、输入使用各 Page 独立通道；导航等待 response commit，不等待 DOMContentLoaded 才允许画面更新。
  连续文本/滚轮在 25ms 内合并，按键顺序保留；输入与截图不会被另一个网页的导航锁住。
- WebSocket 继续走账号 Cookie/撤销网关，强制精确 Origin 与 `pi-browser-v1` 子协议；
  仅接受帧 ACK，不接受 CDP、JavaScript 或输入命令。所有操作仍经过原 REST 白名单和 Session 校验。
- 公网代理最多尝试 4 个已校验的数字地址，每地址 2 秒、总建连预算仍有界；不回退到未校验主机名。
  **全量请求拦截及其 HTTP 缓存限制暂保留**：没有为性能删除网络安全检查，也没有擅自配置系统/上游代理。

真实 Google/高清像素/运动帧率与回归证据见 [性能验证记录](../validation/workspace-browser-performance-2026-09-09.md)。

## 常驻单标签 1080p / 30 fps（2026-09-11）

可见优先浏览器默认使用固定 1080p、目标 30 fps 的 VP8/Opus 实时媒体，初始静音。
需要声音时勾选 **Sound**，由前端真实用户点击解锁音频；音量只控制当前接收端播放。
网站本身也需处于可播放、非静音状态。若浏览器拒绝播放，点击 **Play video**，不绕过其策略。
媒体画面等比例显示，不随容器宽度改变源分辨率。

- **HD screenshots** 可手动选择，**Stop video** 同样切回图片。当前应用窗口以内存记住
  Session/page 的模式和失败状态，最多 256 项；不持久化声音授权、URL 或登录数据。
- 每账号只允许一路媒体；同一应用窗口内转移前先确认旧流停止。只有一个可见浏览器时，
  点击邻侧 Markdown 不影响它；两个浏览器分屏时，仅焦点所在浏览器优先使用媒体，另一侧用图片。
  跨应用窗口仍由后端账号配额兜底，不抢停其他窗口的流。
- 隐藏、切换后媒体标签不再可见、切换 Session、关闭、退出均停止。正常返回时恢复所选媒体模式，
  但声音重置为关闭；手动选择图片或已进入待重试故障的页面不会被强制切回媒体。
- 失败后明确回退图片，使用 **Retry 1080p / 30 fps** 手动重试，不无限重连。
  状态栏显示实际帧率；静态页只有在媒体片段和播放器时钟仍推进时才显示健康，不伪造高帧率。
- `pi-browser-media-v2` 的 `started` 先确认 page/generation；清理只停止当前视图持有的 generation，
  配额拒绝和迟到旧请求不能误停另一个窗口或同页新流。原账号、Origin、Session 校验保持不变。

不能保证所有机器/网站恒定 30 fps；后台音频、60 fps、多路媒体和 DRM 不属于本轮交付。
实现、权限与性能证据见 [音视频设计](workspace-browser-media.md) 及
[常驻验证记录](../validation/workspace-browser-persistent-2026-09-11.md)。

## 权限与资源

- 复用登录网关、账号 Workspace 隔离、可信 Host/Origin/UI header；不暴露 CDP、任意脚本执行或 Cookie API。
- Chromium 出网走私有、认证的本机代理：解析并校验公网 IP 后连接固定 IP，阻断私网、loopback、链路本地、
  混合 DNS 答案和非常规端口。默认仅 HTTP 80 / HTTPS 443；不剥离站点 TLS 或嵌入保护。
- 浏览器不继承 Provider 密钥环境变量。非持久登录状态不导出到业务 SQLite/前端存储/日志。
- 不支持本机文件、下载/上传、用户自定义扩展、摄像头/麦克风、剪贴板读取及自动 Agent 控制。
  仅内部加载项目自带的标签采集扩展，不安装到日常浏览器，不开放远程调试端口。
  输入由用户明确操作；键盘/密码/页面帧不写审计正文、不送给模型。
- 每账号浏览器有界上下文/页面数量，闲置自动关闭；关最后网页、删除 Session、后台退出释放资源。
  会话删除若浏览器清理失败则不宣称成功。
  当前上限为每账号 3 个 BrowserContext、每 Session 6 个网页、每 Session 共 16 个文件/网页标签。
  无用户操作 15 分钟后回收（30 秒检查一次）；截图/信息轮询不延长生命周期。
  有效媒体消费另有短观看租约，媒体停止后恢复正常空闲回收。

## 产品边界

- 这是可交互网页浏览器首版，不等同完整桌面 Chrome：DRM、系统文件选择器、Passkey、
  浏览器扩展和某些反自动化站点不保证支持；不绕过验证码或访问限制。
- 登录在同一 Session 的网页间共享，但服务重启、闲置回收或关闭该 Session 最后网页后失效。
- 图片回退支持阅读/表单/常规操作，不以流畅视频作为图片模式的验收指标；媒体另有单路播放验收。
- BrowserContext 提供站点状态隔离，不是额外的操作系统隔离环境；保留 Chromium sandbox。

## 安装与使用

在运行 Web 后端的同一 Python 环境中安装可选依赖，然后重启后端：

```powershell
python -m pip install -e ".[web,browser]"
python -m playwright install chromium
```

音视频路径需要 Playwright >=1.62 和完整 Chromium；不要只安装 headless shell。

Web 中打开一个 Session，在 Workspace → files 分隔线下：

1. 点击 **New Markdown**，在文件列表区域填写路径和内容并创建。
2. 点标签栏末尾 **＋** 新建网页，在地址栏输入公网网址并按 Enter/Go。
3. 在页面内点击、键入、滚动；用户手动登录。新弹出页面成为同 Session 的网页标签。
4. 选择 **Split left/right** 或 **Split top/bottom**，同时查看 Markdown 与网页。
   可拖宽 Workspace；点击某个分屏后再选择标签，替换该分屏的内容。
5. 关闭 Markdown 标签不会删文件，未保存草稿先确认；关闭最后网页会结束该 Session 的网页登录状态。
6. 当前优先浏览器默认静音播放 **1080p / 30 fps**；需要声音时勾选 **Sound**。
   返回标签或 Session 后需重新启用声音。需要图片模式时选择 **HD screenshots** 或点击 **Stop video**；
   故障回退后可点 **Retry 1080p / 30 fps**，其余网页继续使用图片模式。

浏览器依赖缺失只影响新建网页，普通聊天/Markdown 仍可用；不会自动下载安装。
刷新 Web 页会丢失未保存 Markdown 草稿（有离开提醒），已保存文件不受影响。
后端未重启且未过期时可重新枚举网页；不将网页标签或登录状态持久化到 SQLite。
